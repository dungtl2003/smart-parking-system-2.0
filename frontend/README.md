## GUIDE TO RUN PROJECT

- Config your .env file (or use [the default one](./.env) is ok)<br>
  Then run the following command:
- Install all dependencies

```bash
npm i
```

- Run in dev mode

```bash
npm run dev
```

## DEVELOPMENT

Setup husky:

```bash
npm run prepare
```

Format code:

```bash
npm run format
```

Check invalid code:

```bash
npm run lint
```
