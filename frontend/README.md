## FOR DEVELOPEMENT

- Config your .env file (or use [the default one](./.env) is ok)<br>
  Then run the following command:
- Install all dependencies

```bash
npm i
```

- Run in dev mode

```bash
npm run dev
```

- You can setup husky (optional):

```bash
npm run prepare
```

- Format code (optional):

```bash
npm run format
```

- Check invalid code (optional):

```bash
npm run lint
```
